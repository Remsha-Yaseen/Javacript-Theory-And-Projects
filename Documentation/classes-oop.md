
# JavaScript Classes & OOP
-----------


## 1. Class Basics & Expressions
* **Classes**: Blueprints for creating objects and encapsulating state and behavior.
* **`constructor()`**: A special method automatically invoked with `new` to initialize instance properties using `this`.
* **Methods**: Functions defined inside a class defining instance behaviors.
* **Class Expressions**: Anonymous or named classes assigned directly to variables.

## 2. Inheritance & The `super` Keyword
* **`extends` Keyword**: Implements inheritance, enabling child classes to inherit properties and methods from a parent class.
* **`super()`**: Used in child constructors to call the parent class's constructor and access parent methods/properties.

## 3. Static Methods & Properties
* **Static Methods**: Utility or factory functions associated with the class itself rather than instances (cannot access `this` instance data directly).
* **Static Properties**: Class-level variables shared across all instances and accessed directly via the class name.
